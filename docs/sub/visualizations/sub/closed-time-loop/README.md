# Closed Time Loop Without Branching

Status: draft

![Closed time loop without branching](../../assets/default/diagrams/closed-time-loop.svg)

This diagram visualizes the Ontoverse **Closed Time Loop** model: a past-directed transit that remains part of one realized historical trajectory instead of creating an alternate branch.

## What the Diagram Shows

The horizontal line is the single primary realized history.

Two highlighted nodes define the closed loop:

- **reintegration into past history** — the traveler rejoins an earlier state of the same history;
- **departure from future** — the later event at which the same traveler leaves the primary flow and enters the isolated past-directed transit.

The dashed path below the primary history is the isolated transit. Its body is deliberately drawn as a smooth oval-like loop rather than as a second straight timeline or a rectangular detour.

There is no divergence line at the departure node. The callout `same primary timeline — no branch created` points directly to that node because the departure closes the loop rather than opening a new future.

## Parameter-Enriched Interval

The primary trajectory is drawn thicker and brighter between reintegration and departure.

This encodes the model's current interpretation that, after reintegration, the realized interval carries an expanded state description that includes the traveler and the consequences of the earlier arrival.

The line returns to its baseline thickness after the departure event. This represents closure of the model's parameter-accounting loop, not destruction of information or creation of another universe.

## Frontal Time Plane

The ruby **frontal time plane** is conceptually unbounded.

The SVG therefore draws a planar slice that extends beyond the top and bottom of the visible viewport. It is not a small rectangular obstacle that either trajectory can go around.

Both the primary history and the isolated transit visibly cross the plane. The translucent ruby overlay remains visible over the crossing regions so the geometry reads as an intersection with the plane.

This page explicitly uses frontal time as a reference ordering slice across a complete closed causal loop. That differs from Ontoverse diagrams where the frontal time plane is used as the present boundary and realized trajectories terminate at it.

## Direction and Geometry

The primary history has no arrow pointing into the past.

The transit path begins at the departure node with the local tangent of the primary trajectory, curves through an oval-like loop, crosses the frontal time plane, and reconnects at the earlier reintegration node.

The absence of an arrow into the past is intentional: the diagram emphasizes topology and causal closure rather than treating the past as an ordinary spatial direction.

## Conceptual Reading

```text
future departure
-> isolated past-directed transit
-> reintegration into earlier history
-> temporarily parameter-enriched interval
-> same future departure
```

The future state shown before departure already contains the consequences of reintegration. A perturbation introduced after arrival in the past is therefore interpreted as part of the causes of that future, not as a butterfly-effect rewrite into another branch.
