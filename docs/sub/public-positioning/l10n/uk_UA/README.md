# Публічне позиціонування

Статус: чернетка

Ontoverse — самостійно розроблений концептуальний фреймворк для організації уявлень про реальність, концепції та можливі приховані зв’язки між ними.

Його не слід подавати як завершену наукову теорію, доказ, містичне твердження або заміну усталеній фізиці.

Публічна цінність Ontoverse дослідницька: він зберігає спекулятивні інтуїції у структурованій формі, щоб їх можна було перевіряти, критикувати, порівнювати з наявними ідеями, уточнювати, формалізувати або відкидати.

## Рекомендований однорядковий опис

Самостійно розроблений концептуальний фреймворк для організації уявлень про реальність, концепції та можливі приховані зв’язки між ними.

## Питання для медіа

Чи може персональний концептуальний фреймворк виявити корисну структуру до того, як наука має для неї формальну назву?

## Обіцянка читачеві

Ontoverse має чітко показувати, що саме стверджується, що лише досліджується і що залишається нерозв’язаним.

Скептичний читач повинен мати змогу визначити:

- основну інтуїцію;
- запропоновану термінологію;
- аналогію або мотивуючу ідею;
- зв’язок з наявними концепціями;
- припущення;
- слабкі місця;
- відкриті завдання формалізації.

## Бажані формулювання

Використовуйте рамки на кшталт:

- концептуальний фреймворк;
- преформальна модель;
- структурований дослідницький блокнот;
- спекулятивна, але обмежена гіпотеза;
- інтерпретаційна аналогія;
- запропонована термінологія;
- відкрите завдання формалізації;
- порівняння з наявними концепціями;
- раціональне зерно для майбутнього відкриття або підтвердження.

## Уникайте

Уникайте формулювань, що натякають на:

- доказ;
- остаточну істину;
- містичний авторитет;
- походження зі сну, якщо це явно не задокументовано автором;
- заміну усталеної фізики;
- розв’язану квантову механіку;
- новий закон фізики;
- наявне наукове підтвердження;
- приховану істину, відкриту без формальної підтримки.

## Безпечний публічний підсумок

Ontoverse не стверджує, що нову фізичну теорію вже доведено. Це спроба організувати набір концептуальних інтуїцій, гіпотез та інтерпретаційних моделей так, щоб їх можна було перевіряти, оскаржувати, порівнювати, уточнювати, формалізувати або відкидати.

Проєкт має цінність лише настільки, наскільки його структура допомагає побачити, які частини корисні, які дублюють наявні ідеї, які вводять в оману, а які можуть заслуговувати подальшої формалізації.
