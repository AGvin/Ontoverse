# Чекліст перевірки

Статус: чернетка

Використовуйте цей чекліст перед перенесенням дослідницького матеріалу Ontoverse до стабільної документації або перед публікацією зовнішніх пояснень.

## Переклади

- [English](../../)
- Українська

## Межі тверджень

- Чи чітко сторінка позначає свій статус?
- Чи не подає вона спекулятивні компоненти моделі як усталену науку?
- Чи не натякає на доказ, підтвердження або завершену теорію?
- Чи чітко відділяє те, що стверджується, від того, що лише досліджується?
- Чи може скептичний читач зрозуміти, чого сторінка **не** стверджує?

## Якість концепції

- Чи визначені ключові терміни до того, як вони починають активно використовуватися?
- Чи позначені запропоновані терміни як термінологія Ontoverse?
- Чи явні припущення?
- Чи видно слабкі місця й нерозв’язані питання?
- Чи перелічені відкриті завдання формалізації там, де це доречно?

## Зв’язок з наявними ідеями

- Чи відділено усталений фон від інтерпретації Ontoverse?
- Чи пояснено, чи є концепція аналогією, гіпотезою або запропонованим компонентом моделі?
- Чи не заявляється еквівалентність наявній фізиці без демонстрації такої еквівалентності?
- Чи розміщені зовнішні наукові джерела або джерела натхнення поруч із твердженнями, що на них спираються?

## Публічна подача

- Чи відповідає сторінка позиціонуванню Ontoverse як самостійно розробленого концептуального фреймворку?
- Чи уникає містичної подачі, необґрунтованої впевненості та риторики «великої теорії»?
- Чи зберігає різницю між корисною спекуляцією та непідтриманим твердженням?
- Чи робить проєкт легшим для критики, а не складнішим для оскарження?

## Правило перенесення

Переносьте матеріал із `notes/` до `framework/`, `models/`, `glossary/` або інших публічних сторінок лише тоді, коли термінологія та межі достатньо стабільні для повторного використання.

Якщо є сумнів, залишайте матеріал у `notes/` і позначайте його як дослідницький.
