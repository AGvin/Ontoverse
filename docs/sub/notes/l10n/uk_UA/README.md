# Нотатки

Статус: чернетка

Цей розділ містить дослідницькі нотатки, джерела натхнення, порівняння та чернеткові думки, які ще не є частиною стабільного фреймворку.

## Переклади

- [English](../../)
- Українська

## Розділи

- [`inspiration/`](../../sub/inspiration/l10n/uk_UA/) — вихідні відео та ідеї, що мотивували перше формулювання Ontoverse.

## Правило перенесення

Переносьте матеріал із нотаток до `framework/`, `models/` або `glossary/` лише після того, як термінологія стане достатньо стабільною для повторного використання в репозиторії.
